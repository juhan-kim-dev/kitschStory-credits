옛 지면 그림은 쪽 전체 또는 그림 부분만 잘라 화면에 온전히 넣었고, 남는 자리는 종이 빛깔 바탕으로 채웠습니다. 2·6·7번 항목에서는 3초 남짓 「AI로 그린 그림」과 반씩 나란히 보여 줍니다. 그림 위에 한국어 설명 한 줄과 출처를 덧붙였습니다. 8번의 목판화에는 지면의 그림 제목과 학명이 함께 보입니다(정체를 밝힌 뒤에만 나옵니다). 5번 항목의 「그림은 1806년 왕립학회 지면의 도판」 대목에 나오는 것이 이 도판 X·XI입니다.

## 자체 제작 요소

- 화면에 「AI 재현」 표시가 붙은 그림, 항목 카드 속 그림 10장, 영상 처음과 끝의 책상 그림 1장은 생성 이미지이며, 실제 사진이 아닙니다. 옛 기록의 문장을 그대로 그린 그림, 기록 속 장면을 그린 그림, 추정한 정체로 다시 그린 그림, 설명 그림이 여기에 해당합니다. 항목 카드 속 그림은 정체를 미리 드러내지 않으려고 짐승을 실루엣으로 가렸습니다.
- 1·2·4·5·7·8·9·10번 항목에서 정체를 밝히는 순간 「기록대로 그린 그림」이 같은 구도의 정체 그림으로 바뀌는 장면도 생성 이미지를 이어 붙인 것입니다.
- 3번 항목(외눈 송아지)에는 실제 사진이 없어, 「그림은 외눈증을 가진 송아지를 AI로 다시 그린 것」 대목의 그림도 생성 이미지입니다. 10번 항목의 1935년 신문 사진은 구하지 못해 화면에 싣지 않았고, 신문이 놓인 장면은 생성 이미지입니다.
- 썸네일의 그림도 생성 이미지입니다.
- 생성 이미지에는 글자를 넣지 않았습니다. 항목 카드의 글과 카드에 옮긴 원문 줄과 그 풀이, 화면 자막, 길이를 사람 키와 견준 눈금 쪽지는 직접 넣었습니다.
- 배경음악은 생성 모델로 만든 곡입니다. 항목이 바뀔 때의 셔터 소리와 영상 처음 그림이 떨어지는 소리는 표기 의무가 없는 효과음입니다.
